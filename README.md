## Auto Update From LeetCode

Recommended setup:

1. Create a GitHub repository named `leetcode-solutions`.
2. Push this folder to that repository.
3. Install a browser extension such as LeetHub v2.
4. Connect the extension to your GitHub account.
5. Select the `leetcode-solutions` repository.
6. Submit an accepted solution on LeetCode.
7. The extension will commit the accepted solution to GitHub automatically.
